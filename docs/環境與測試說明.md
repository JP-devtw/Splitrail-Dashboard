# 環境與測試說明

給第一次使用、或想確認自己的環境能不能跑這個儀表板的人。照「安裝」做完後，依「測試步驟」逐項確認即可。

## 1. 系統需求

| 項目 | 需求 | 備註 |
| :-- | :-- | :-- |
| 作業系統 | Windows 10／11 | 讀 Antigravity 行程資訊用到 `tasklist`、`netstat`、`cscript`（Windows 內建）；macOS／Linux 未支援 |
| Python | 3.9 以上 | 只用標準函式庫，不需要 `pip install`；作者環境為 3.12.10，其他版本未實測 |
| splitrail | 放在本資料夾的 `splitrail.exe` | 只用來算 Claude Code 的花費；作者環境為 3.10.1 |
| 瀏覽器 | 任一現代瀏覽器 | 開啟產生的 `splitrail-dashboard.html` |

**要看哪一家，就要先登入哪一家的 CLI**（沒用的可以不裝，對應卡片只會顯示提示）：

| 服務 | 前置條件 | 讀取的本機資料 |
| :-- | :-- | :-- |
| Claude Code | 用 claude.ai 訂閱帳號登入過 Claude Code CLI（`claude auth status` 顯示 `loggedIn: true`） | `~/.claude/.credentials.json`、`~/.claude/projects/` |
| Codex | 用 ChatGPT 帳號登入過 Codex CLI（`~/.codex/auth.json` 存在） | `~/.codex/auth.json`、`~/.codex/sessions/`、`~/.codex/archived_sessions/` |
| Antigravity | 使用過 Antigravity（CLI、IDE 或 App）；**額度**要 App 或 `agy` 正在執行才抓得到 | `~/.gemini/antigravity*/conversations/` |

## 2. 安裝

1. 下載或 clone 本 repo 到任意資料夾。
2. 下載 [splitrail](https://github.com/Piebald-AI/splitrail/releases) 的 Windows 版壓縮檔，把 `splitrail.exe` 放進本資料夾。
   **建議比對雜湊值**，確認檔案跟 GitHub 上發佈的一致：
   ```powershell
   # GitHub 記錄的 SHA-256（把 v3.10.1 換成你下載的版本）
   gh release view v3.10.1 --repo Piebald-AI/splitrail --json assets --jq '.assets[] | "\(.name)  \(.digest)"'
   # 你下載的壓縮檔的 SHA-256，兩者要一致
   Get-FileHash .\splitrail-*.zip -Algorithm SHA256
   ```
3. 確認 `python --version` 能執行。

## 3. 測試步驟

每一步都有「怎樣算通過」，做不到就看第 4 節的疑難排解。

| # | 操作 | 通過條件 |
| :-- | :-- | :-- |
| T1 | 執行 `splitrail-dashboard.bat --text` | 印出三家工具的表格（對話數、活動天數、累計／近7天／近30天／今日費用），沒有錯誤訊息 |
| T2 | 雙擊 `splitrail-dashboard.bat` | 產生 `splitrail-dashboard.html` 並自動在瀏覽器開啟 |
| T3 | 看網頁左邊的總花費卡片 | 甜甜圈有資料；切換 Cost／Cost per MTok／Tokens 和 Today／Yesterday／30 Days 會跟著變 |
| T4 | 看 Claude Code 卡片 | 顯示方案（例如 Pro）、5 小時與每週額度條、重置倒數；滑鼠移到花費數字上會出現分模型明細 |
| T5 | 看 Codex 卡片 | 顯示方案與額度條；花費有分模型明細 |
| T6 | 看 Antigravity 卡片 | 花費有資料；額度在 App／`agy` 沒開時顯示「沒有在執行」，開著再跑一次 T2 會出現額度條 |
| T7 | 把瀏覽器縮成約 1280×560（例如 Windows 顯示縮放 150% 的 1920×1080 筆電） | 一頁放得下、不用捲動；視窗再窄會自動變成單欄 |
| T8 | 執行 `splitrail-dashboard.bat --no-open` | 只更新 HTML、不開瀏覽器 |
| T8b | 執行 `splitrail-dashboard.bat --loop`，等 5 分鐘 | HTML 的修改時間每 5 分鐘更新一次；按 Ctrl+C 結束 |
| T9 | Claude token 自動換新（選做） | 見下方說明 |

**T9：確認 Claude token 自動換新正常**

Claude 的 access token 約 8 小時過期；只用 Claude 桌面 App、不跑 CLI 時，憑證檔不會被更新。這時儀表板會自動換新：

```powershell
# 換新前後各看一次 token 到期時間（只印到期時間，不印 token 本身）
python -c "import json,os,datetime; o=json.load(open(os.path.expanduser('~/.claude/.credentials.json')))['claudeAiOauth']; print(datetime.datetime.fromtimestamp(o['expiresAt']/1000))"
```

到期時間已過（或 5 分鐘內到期）時跑一次 T2，再看一次：到期時間應該往後延，同資料夾多一個 `.credentials.json.splitrail-bak`（換新前的備份），而且 `claude auth status` 仍顯示已登入。

## 4. 疑難排解

| 卡片／畫面上的訊息 | 原因 | 處理 |
| :-- | :-- | :-- |
| 找不到 splitrail.exe | 執行檔沒放在本資料夾 | 照安裝第 2 步 |
| 找不到 Claude 憑證 | 沒用 CLI 登入過 | 執行 `claude` 登入一次 |
| Claude 登入已失效，請執行 claude auth login | refresh token 已失效（例如太久沒用、或被其他工具換掉） | 執行 `claude auth login` |
| Claude token 更新失敗（HTTP 403） | 公司網路／防火牆擋了 `platform.claude.com` | 換網路或請 IT 放行 |
| Codex token 已失效 | Codex 的 token 過期 | 在終端機跑一次 `codex` |
| Antigravity 沒有在執行 | App／`agy` 沒開 | 開啟後重跑；只影響額度，不影響花費 |
| 額度 API 回應 HTTP 429 | 查詢太頻繁 | 等幾分鐘；背景更新間隔是 5 分鐘 |

## 5. 安全與隱私須知（分享前請讀）

- **本工具會改寫 `~/.claude/.credentials.json`**：Claude token 過期時自動換新並寫回，寫入前備份到同資料夾的
  `.credentials.json.splitrail-bak`。這兩個檔案都含登入資訊，**不要傳給別人、不要放進任何 repo**。
- **不要同時執行其他也會換 Claude token 的工具**（例如 Pane、OpenUsage）。refresh token 用過即作廢，兩個程式同時換新會互相作廢，Claude Code CLI 會被迫重新登入。
- **資料只送到各服務的官方主機**：Claude token 只送 `api.anthropic.com`、`platform.claude.com`；Codex token 只送 `chatgpt.com`；Antigravity 只連本機 `127.0.0.1`。沒有遙測、不會上傳用量。
- 產生的 `splitrail-dashboard.html` 含你的用量與花費，已列在 `.gitignore`，不會被 commit。
- 花費是用本機 token 紀錄乘上官方 API 單價的**估算值**，不是帳單金額。
